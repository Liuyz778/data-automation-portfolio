# 30 天行动计划：从 0 到第一笔收入

## 第 1 周：铺好摊子

- [ ] 注册 GitHub，把 `portfolio/` 文件夹推上去（公开仓库，名字如 `data-automation-portfolio`）
- [ ] 把 `report_preview.png` 和 `dashboard_preview.jpg` 再用 Excel / 浏览器截几张高清图，做 Gig 封面（Fiverr 要求 1280×769）
- [ ] 注册 Fiverr 卖家账号：头像用真人照片（通过率高很多），填写 `fiverr_gigs.md` 里的 About me
- [ ] 发布 3 个 Gig（文案直接复制 `fiverr_gigs.md`）
- [ ] 注册 Upwork，Profile 填到 100%，通过身份验证，发布 `upwork_profile_and_proposals.md` 里的 Overview
- [ ] 注册 Payoneer（Fiverr 和 Upwork 都支持，能提现到马来西亚银行）
- [ ] 把 Streamlit 仪表盘部署到 Streamlit Community Cloud（免费），拿到一个公开链接放进 Gig 和 Profile

## 第 2 周：开始投标 + 刷存在感

- [ ] Upwork 每天投 3–5 个单，严格按 `upwork_profile_and_proposals.md` 的筛选标准
- [ ] Fiverr 每天上线至少 1 次（在线状态影响排名），回消息控制在 1 小时内
- [ ] 第一单哪怕只有 $20 也接，目标是 5 星评价，不是利润
- [ ] 在 Reddit r/forhire、r/slavelabour，以及 LinkedIn 发 1 条"我能帮你自动化 Excel 报表"的帖子，附作品链接

## 第 3–4 周：交付与复盘

- [ ] 每接一单：把客户需求原文发给我，我出代码 + 测试 + 交付说明，你负责沟通和验收
- [ ] 交付时附 1–2 分钟录屏（用 Windows 自带 Xbox Game Bar 或 Loom），客户好评率会明显提高
- [ ] 交付后 2 天礼貌提醒评价
- [ ] 每周日复盘：投了多少、回复多少、成交多少、哪类需求最多

## 关键数字（第 1 个月目标）

| 指标 | 目标 |
|---|---|
| Upwork 投标 | 60–80 个 |
| Upwork 回复率 | ≥ 10% |
| 成交 | 2–4 单 |
| 收入 | $100–400 |
| 5 星评价 | ≥ 2 个 |

## 第 2 个月起

- 每拿 5 个好评，Gig 价格涨 30%
- 把重复出现的需求做成固定产品（比如"Shopee/Lazada 价格监控"），这是通向被动收入的入口
- 开始考虑路线 1（SaaS）或路线 2（内容自动化）

## 合规提醒

- 只抓公开数据，不碰需要登录的个人信息（LinkedIn 私人资料、Facebook 等）
- 客户发来的数据不外传、交付后删除
- Fiverr/Upwork 禁止站外交易，前几单不要引导客户私下付款，会封号
